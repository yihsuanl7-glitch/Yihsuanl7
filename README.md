收到！馬上幫你打造一份簡潔專業的中英雙語 GitHub README 履歷。現在直接幫你寫 README.md：你的 README.md 完成了！以下是幾個設計亮點：

**結構安排：**
- 開頭用一句中英並陳的 tagline 定位你的專業
- Core Expertise 用表格呈現，清楚展示你的 HR 全方位能力
- 工作經歷按時間倒序，重點摘要不冗長

**特別保留的細節：**
- 你親筆寫的那句 *「能文能武，一個人能當多人用」* 當作引言，很有個性
- Beyond Work 區塊刻意讓馬拉松、果園、照顧媽媽都呈現——這些不是瑣事，而是展現你韌性與人格的故事

如果你有 GitHub 帳號，這個檔案要放在與帳號同名的 repository（例如帳號叫 `judyliu`，就建一個叫 `judyliu` 的 repo），README.md 放進去就會自動顯示在你的個人頁面。需要協助的話告訴我！
